## Что изменилось и почему звёзды больше не аргумент

- ICSE 2026 (He et al., «Six Million Fake Stars»): у 16,7 % репо с 50+★ в 2024
  была накрутка; фейковый всплеск живёт < 2 мес; в GitHub Trending попало лишь
  0,42 % накрученных.
- 30.06.2026 GitHub закрыл `/stargazers` и `/subscribers` для всех, кроме
  админов → детекторы по профилям звездящих (astronomer, RealStars, GitProbe,
  star-history.com) мертвы. Взамен с 04.09.2026 —
  `GET /repos/{o}/{r}/stargazers/history` (недельные корзины). `tools/liveness.sh`
  ловит всплеск по нему.
- OSSInsight trends пустой с 03.2026, Snyk Advisor закрыт, Criticality Score
  без инфраструктуры. Не ссылайся на них.

Scorecard покрывает ~1 млн репо «по зависимостям»: для многих живых проектов
(whisper.cpp, mlx-audio) он 404 → в скрипте нейтральные 0,5. Не аргумент сам
по себе.

Иерархия сигналов: **живость (коммиты/релизы за 90–365 дн) > отклик мейнтейнеров
на чужие PR > распределённость авторов > звёзды**. Звёзды — фильтр отсечения и
детектор всплеска, не доказательство.

## Пять осей (High / Medium / Low) — по одной колонке в таблице

| Ось | High | Medium | Low |
|---|---|---|---|
| fit | делает ровно это | смежно / частично | совпали слова |
| evidence | видел код / тесты / доки на функцию | пример в README | сниппет из выдачи |
| activity | `liveness.sh` ≥ 0,7 | 0,4–0,7 | < 0,4 / архив |
| reuse | понятный API + лицензия, мало подгонки | нужна адаптация | скрытый сервис, неясная лицензия, переписывать |
| momentum (рост) | `liveness.sh` ↑: звёзды/коммиты последних недель выше предыдущих, ≥2 релизов за 180 дн | → ровно | ↓ затухает |
| currency (актуальность) | решает сегодняшнюю задачу на сегодняшнем стеке: последний релиз-нот упоминает текущие модели/API/платформы, есть в свежих сравнениях | стек прошлого года, но рабочий | заточен под ушедшие API/форматы/платформы |
| risk | оговорки ограничены | неизвестные | блокер |

Правило: `fit`, `evidence`, `currency` — из чтения репо, `activity` и
`momentum` — из скрипта, не «на глаз». Кандидат с evidence=Low не попадает
в топ, пока не прочитан.

Актуальность — не то же, что живость. Агенты и платформы уходят вперёд каждый
месяц: проект может пушить еженедельно и при этом решать прошлогоднюю задачу
(старые API соцсетей, снятые модели, форматы, которые площадка уже не берёт).
Проверяй по трём меткам: (1) CHANGELOG/релиз-ноты за 6 мес — что добавили и
под что; (2) даты в README и примерах — модели, версии SDK, названия фич
платформ; (3) кто из живых конкурентов ссылается на него в сравнениях сейчас.
При равной живости бери тот, что растёт (↑) и моложе по стеку, а не тот, у
кого больше звёзд за прошлые годы.

## Пороги живости (если скрипт недоступен, считай руками)

- Последний push < 3 мес — ок; > 18 мес — мимо; `archived` — сразу нет.
- Контрибьюторов за год ≥ 5 и доля не-топ-1 ≥ 0,3 — здоровый; 1 — bus factor 1.
- Отклик на чужие PR ≤ 7 дней и merged/prs ≥ 0,2 — живые мейнтейнеры; > 50 %
  PR от ботов — делить пополам (Nesbitt, 2026: счётчики раздуты агентами).
- 50k★, но коммит 2023 → мёртв: ищи форк-наследник (`gh api repos/O/R/forks?sort=stargazers`).
- Две либы в пределах 2× по звёздам → бери ту, что пушили позже.
- Всплеск: макс-неделя > 10× медианы или одна неделя > 50 % звёзд → подозрение.
  forks/stars < 1 % при > 1000★ — тоже.

## Запахи (до trust-gate)

- Имя как у известного проекта, но в другой организации → typosquat.
- Установка через `curl | bash` с чужого домена.
- Много звёзд, но 0 issues / forks / чужих PR — «реальное использование
  оставляет следы».
- Пакет из памяти ≠ тот пакет: owner сверяй живым `npmSearch`/PyPI, не по имени
  (slopsquatting: фейковый `huggingface-cli` собрал 30K+ скачиваний).
- Лицензии: permissive (MIT/Apache/BSD) — свободно; copyleft (GPL/AGPL) —
  для SaaS вопрос пользователю; fair-code / BSL / FSL — раскрыть, не отбраковывать;
  «no license» — нельзя использовать.

## Словарь углов: пользователь говорит → искать ещё

Потребность на языке пользователя ≠ слова мейнтейнера. Прогони каждую
через оба словаря:

| Человек говорит | Также искать |
|---|---|
| «бот для WhatsApp» | whatsapp api, baileys, waha, evolution api, wa gateway |
| «CRM» | sales pipeline, lead management, helpdesk, shared inbox |
| «расшифровка голосовых» | speech-to-text, asr, whisper, transcription |
| «парсер чеков» | receipt ocr, invoice extraction, document ai |
| «как у <SaaS>» | `<SaaS> alternative`, `open source <SaaS>`, `self-hosted <SaaS>` |
| «скилл / агент для X» | agent skill, mcp server, claude code plugin, SKILL.md |
| «модель для языка / задачи X» | Hugging Face Hub `api/models?search=<lang> <task>` — дообучки живут там, GitHub их не видит |

Плюс всегда: term-of-art домена (как это называют в статьях), смежный подход
(другая архитектура той же задачи), название пакета/протокола.

## Четыре канала кроме поиска

1. Awesome-списки: `awesome <тема>` + `awesome.ecosyste.ms/api/v1/lists?mailto=`.
2. Страницы топиков: `github.com/topics/<topic>?o=desc&s=updated`.
3. Snowball: README ближайшего найденного — хорошие проекты ссылаются на
   соседей и предшественников в таблицах сравнения.
4. Веб: `best open source <тема> 2026`, `<тема> comparison`, HN
   (`hn.algolia.com/api/v1/search?query=github.com/O/R&tags=story`).
5. Реестры: PyPI/npm по скачиваниям → `project_urls` → репо; для моделей —
   Hugging Face Hub (карточка модели даёт WER/бенчмарк, которого нет на GitHub).
6. Что растёт сейчас (новички, которых best-match прячет за старыми гигантами):
   - `ghSearch operation:"repositories"` с `created: ">СЕГОДНЯ−12мес"`,
     `sort: "stars"` — лучшие из молодых;
   - `gh search repos "<тема>" --sort updated --updated ">СЕГОДНЯ−30д"`;
   - зеркала GitHub Trending: `curl -s https://quantavil.github.io/trendshift/data/daily/daily-all.json`
     (или `daily-python.json` и т.п.; `index.json` — только манифест), RSS
     `https://mshibanami.github.io/GitHubTrendingRSS/daily/all.xml` — 15 строк
     в день, по узкой теме почти всегда пусто, не рассчитывай;
     JS/TS — `https://bestofjs-static-api-v2.vercel.app/projects.json` (поле `trends`).
   OSSInsight-тренды и star-history.com мертвы — не ссылаться.

## Когда остановиться

- Финалист подтверждён кодом, повторные запросы дают тех же → стоп.
- ≥ 2 выживших после фильтров → выдавай выбор + trade-offs, не «единственный».
  «Unknown» ≠ «pass»: непроверенная ось — так и пиши.
- Лицензия/скрытый сервис требуют решения пользователя → вопрос, не догадка.
- Глубже только с клоном или запуском → сначала `trust-gate` и разрешение.
