# github-finder — скилл для Claude Code

Ищет на GitHub готовые решения под твою задачу: библиотеки, движки, инструменты,
куски кода. Не выдаёт список ссылок по звёздам. Вместо этого он:

- ищет с 3–4 разных сторон, потому что один запрос пропускает половину находок;
- проверяет скриптом, жив ли проект: коммиты, релизы, отвечают ли авторы;
- открывает код финалистов и смотрит, есть ли там нужная функция на самом деле;
- возвращает таблицу из 3–5 кандидатов, называет одного лучшего и объясняет, чем
  придётся заплатить за каждый вариант.

Скилл только ищет и сравнивает. Сам он ничего не устанавливает и не запускает.

## Установка за 1 минуту

### Вариант А: попроси своего Claude

Открой Claude Code и вставь ему это сообщение:

```text
Установи мне скилл github-finder глобально, чтобы он работал во всех проектах:
1. Склонируй https://github.com/saytimmi/github-finder в ~/.claude/skills/github-finder
2. Сделай исполняемым tools/liveness.sh
3. Проверь, что стоят gh, jq, curl, bc и node. Если чего-то нет, поставь
   (на Mac через brew) и скажи мне, если нужно залогиниться в gh.
4. Скажи, когда закончишь, и что мне перезапустить Claude Code.
```

### Вариант Б: руками (Mac / Linux)

```bash
git clone https://github.com/saytimmi/github-finder ~/.claude/skills/github-finder
chmod +x ~/.claude/skills/github-finder/tools/liveness.sh

# инструменты (Mac)
brew install gh jq node
gh auth login        # нужен аккаунт GitHub, без него поиск не работает
```

На Windows папка такая: `C:\Users\<имя>\.claude\skills\github-finder\`. Скрипт
проверки живости запускается там через Git Bash или WSL.

После установки **перезапусти Claude Code**. Проверить, что скилл подхватился,
можно командой `/skills`.

> Почему именно `~/.claude/skills/`? Это глобальная папка: скилл будет работать
> в любом проекте. Если положить его в `.claude/skills/` внутри одного проекта,
> он будет работать только там.

## Как пользоваться

Пиши обычными словами, скилл включится сам:

- «найди на гитхабе готовый движок для 2D-платформера»
- «есть ли готовая библиотека для инвентаря в Godot?»
- «не пиши сам, найди готовое: генерация подземелий»
- «кто уже сделал мультиплеер для браузерной игры?»

## Обновление

```bash
git -C ~/.claude/skills/github-finder pull
```

## Что внутри

| Файл | Зачем |
|---|---|
| `SKILL.md` | инструкция для Claude: как искать, отсеивать и сравнивать |
| `references/scoring.md` | как оценивать кандидатов и какими словами ещё искать |
| `references/octocode-cli.md` | шпаргалка по поисковику octocode (запускается через `npx`, ставить не нужно) |
| `tools/liveness.sh` | считает, жив ли репозиторий: коммиты, релизы, отклик авторов, рост |
